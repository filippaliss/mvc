DeckOfCards.php : 14

DeckOfCards class represents a standard deck of playing cards.

This class manages a complete deck of 52 playing cards (4 suits × 13 symbols). It provides methods to shuffle the deck, draw cards, and retrieve HTML representations of the remaining and drawn cards.
